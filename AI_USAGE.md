# AI Usage

Large Language Models (LLM) such as ChatGPT and Claude provide software developers powerful tools that can write lots of application code in a short period of time with a simple few paragraphs of natural language describing what you want the code to do.  

Tools like this however can make it difficult to effectively review code, as the amount of code generated in such a short period of time 
can make it overwhelming for human developers/engineers to review.  This can lead some low quality software code making it into pipelines and delployed to production systems.

There is also the concern of "AI brain rot", where if a developer has the LLM write all its code, that developer may not truly learn how to write quality software code for him/herself or know what it looks like.  Therefore it is important for engineers to assess code generated by an LLM before "attaching one's name to it".

## How I used AI/LLMs for this application

I personally do not have a paid subscription to ChatGPT, Claude or any other frontier LLM service provider.  Therefore I am limited to "free tier" quotas and typically restrict my usage of LLMs to the following:
 - Helping me define project or package skeletons 
 - Reporting an issue I face to the LLM when I "hit a wall" so to speak and Google/Stack Overflow yields me nothing

Below are the prompts I entered into an LLM and how I assessed utilized the LLM output:

### 1 (ChatGPT)

I first wanted guidance on a skeleton project structure for this application with effective separation of concerns.

```
I want to build a Java Spring Boot application that connects to an H2 database 
that stores retrieve time-series data.  The application will have a GET endpoint 
to retrieve a collection of records given a range of dates and a GET endpoint to 
return a record given a specific date. Describe to me how I would organize the 
folder structure for such a project given controller, service and repository layer 
based on standards and best practices for Spring Boot. Also describe to be how unit
 tests would be organized.
```

The response gave me a recommended project skeleton that provides the folder structure for this project:

 - config
 - controller
 - data
 - dto
 - entity
 - exception
 - mapper
 - repository
 - service
 - util

This output was more or less what I expected in a conventional Spring Boot project.  However, as I haven't worked much in Java in my current role (I mostly work in Python right now), I wanted to see how much an LLM would confirm my bias of how to structure a Spring Boot project.

I also wanted to keep this prompt vague and not make it specific to this challenge in order to limit the temptiation of copying/pasting code from the LLM without reviewing it.

### 2 (Claude)

As I implemented and verified the API with small datasets, I wanted to load entire conversion rate history for a handful of currencies at application startup.  I wanted some guidance on how to accomplish this with Spring Batch so I asked Claude...

```
I have a functioning currency exchange rate application using Spring Boot that provides the following endpoints:

GET /api/currencies -> provides a list of available currencies to convert to EUR
GET /api/currencies/{code} -> provides a historical list of daily exchange rates to EUR given the currency code provided as {code} returned as a list of JSON objects with currency code and name
GET /api/currencies/{code}/{date} -> provides the exchange rate to EUR given the currency code provided as {code} on the day given as {date} in yyyy-MM-dd format returned as a list of JSON objects with day (in yyyy-MM-dd format) and rate
GET /api/currencies/{code}/{date}/convert -> converts the amount of given currency in {code} on day {date} to Euros given the rate used and the amount of Euros the input amount converts to.  The input amount is defined in the request body as a single attribute JSON object.

I have created the following JPA Entities:

Currency(Long id, String code, string Name)
ConversionRate(Long id, Currency currency, Date date, Double rate)

I want to use Spring Batch to load my database with Currency and ConversionRate rows given a collection of CSV files in my project main/resources folder.  Each CSV holds rows for historical conversion rates for an individual currency in the given format:

{date},{rate}

Example (USD file): 1999-01-08,1.1659,

Each individual CSV represents daily conversion rates for a given currency, with the currency code (eg. USD) in the file name.  Some rows (weekends, holidays) may contain the following entry:

1999-01-09,.,No value available

How would I configure my Spring Batch Config and Jobs to read these CSV files and load them as entities defined above while ignoring rows with "No value available"?  Ideally I want this configured based on Spring Batch best practices with reader, processor and writer.
```

Claude actually provided decent boilerplate for this request.  However, my actual non-functional requirement had a little hitch:

I needed to retrieve the Currency for a conversion rate row from the name of the file rather than any content in the CSV row.  A Google search led me to the use of `MultiResourceItemReader` to accomplish this.  The same applied for my use of LineMapper, though one of the prompts below provided additional guidance here.

A few other prompts I entered into Claude as I attempted to debug:

```
I'm getting the following error when Spring Batch attempts to 
create a Bean for my CurrencyAwareFlatFileItemReader:  LineMapper is required
```

```
Is there a way I can execute this Spring Batch job when I start my spring
 boot application?
```

```
In my importRatesStep, the step does not seem to be loading the last chunk of 
records into the database when the last chunk is less than 100.  How do I get the step to load the final chunk even if it has less than 100 records?
```

```
What I think is actually happening is that jobs are being loaded with the wrong currency due to some parallelism going on in the MultiResourceItemReader.  
The processor for USD seems to be loading some values from the AUD file.
```

Claude's response to the last prompt led me to use `java.util.Map.computeIfAbsent` in `ConversionRateLoaderProcessor` as it appeared there was a race condition when 
loading conversion rate files in parallel.  I decided to store a persistent map for currency code to Currency entity so that each ConversionRate record became properly mapped to the corresponding Currency.

```
I have a Spring boot service method that needs to query a table of conversion rates with an optional 
from date and an optional to date.  I currently have a repository method getConversionRatesByCurrency_CurrencyCodeOrderByDateDesc.  
How would I implement this in a JPA repository method?
```

I gave Claude this prompt in order to add a stretch goal for paging for the `/api/currencies/{code}` endpoint.  

It recommended using a `Specification` implementation which I added to the application and applied to the corresponding 
service method.  I had to make a few adjustments to the repository, including adding a pair of `findAll` functions to get the 
query to execute with JPA Specification and Pagination as expected.  The Specification output appeared useful so I added that to 
my application after a proper review of the code.

## Summary

As mentioned, I used LLMs for this project to verify the project skeleton and provide additional guidance on utilizing Spring Batch to load currency and conversion rate data at server startup.  However, even in these cases, the vast 
majority of the code in this application was written by me and I can gladly and comfortably explain my though process throughout each class in this application.
